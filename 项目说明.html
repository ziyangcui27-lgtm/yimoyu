项目说明 · 熠墨雨（Yimoyu）

让「AI 活起来」 · 温柔倾听、教育陪伴的具身 AI 学伴

一、项目简介

熠墨雨 是一款运行在网页端的 AI 具身学伴应用。她以温柔、耐心、懂教育的女性数字人形象出现，通过语音与文字和用户自然交流，是"陪在身边、随叫随到"的学习伙伴与倾听者。

项目基于 Vue 3 + Vite + 魔珐星云 XingyunAvatarAgent SDK（@xmov/avatar 2.4.1） 构建，纯前端 SPA，可本地运行，也可 Docker 容器化一键部署。

二、场景创意价值

面向学生与需要陪伴的人群，熠墨雨解决的核心问题有三：

  1. 学习陪伴缺失：提供一位温柔、有耐心的数字人学伴，鼓励学生提问、倾听烦恼，缓解学习焦虑。
  2. 实用工具一体化：记忆、任务、闹钟、计算器、天气、网速等生活小工具与对话无缝集成，一站式陪伴。
  3. 让 AI「活」起来：具身形象 + 自然语音 + 真人设，摆脱"工具感"，让 AI 成为有温度的伙伴。

三、技术实现

维度实现
数字人魔珐星云具身 SDK，语音问答 + 文字问答
前端框架Vue 3（Composition API）+ Vite
智能交互流式 LLM 文本接入（onLLMResponse）、ASR 语音识别、TTS 语音播报
数据持久化localStorage（任务 / 记忆）
外部数据Open-Meteo（天气 / AQI）、Cloudflare（网速采样）
稳健性自称兜底、公式清洗、空响应兜底、密钥脱敏
部署多阶段 Docker 镜像，nginx 静态托管

四、产品完成度

已实现并可稳定运行的核心能力：

  • 数字人对话（语音 + 文字）
  • 记忆系统（自动 + 手动，星标优先，携带上下文）
  • 任务系统（清单 + 步骤 + 日期，右侧面板）
  • 闹钟（计时 + 到点语音提醒）
  • 计算器（键盘 + 鼠标）
  • 天气 / AQI / 网速实时监测
  • 深色模式、刷新重连、自称兜底等细节打磨

五、开源规范

  • 采用 MIT 开源许可证
  • 凭据经 .env 读取，.env 不入库，密钥脱敏
  • 提供 README、Dockerfile、docker-compose.yml、.gitignore
  • 支持一键容器化部署，降低复现门槛
